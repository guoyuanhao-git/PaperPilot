# 中文论文阅读规范

## 速览：默认模式

目标是让用户迅速判断想法、证据及是否值得读原文。建议以 3–6 页 PDF 起步；仅导出 PDF；页数是首版建议，应随图表和用户反馈调整，不牺牲可读性以凑页数。

报告开头以无标题、无“段落导读”标签的蓝色背景框，完整展示原论文摘要的中文翻译。正文严格保留“动机 → 方法 → 实验 → 结论”的主线；将相关图表嵌入对应章节，用“问题/现象 → 图表证据 → 解释 → 下一个问题”的连贯叙述串成故事。不要逐图分成独立大章，不要重复套用“看哪里/说明什么/未证明什么”的模板。先核对全部已识别图注及图像；速览根据独立价值全局筛选图表，正文和附录都可舍弃；通常 3–5 幅关键证据即可，不机械凑数，不能固定只取前几张。正文以约 1000 中文字讲清核心因果链，避免逐图说明书。图表标签与正文引用统一使用原始编号的 Figure x / Table x，不显示 PDF 页码或原文定位。不生成重复正文首句的段落导读，重点只在正文中标色。自动识别覆盖范围应如实说明。

采用连续的解释链：问题与瓶颈 → 为什么原有办法不够 → 关键设计如何针对瓶颈 → 实验是否支持 → 对用户的研究主线有什么用。

必要内容：

1. 论文相关：原文标题前加核实的四位发表年月，不翻译标题；只列一作和原文明确标注的通讯作者；多作者论文在原文没有提及通讯作者时默认显示尾作，内部注明为默认推定；单作者论文不能仅因其同时是尾作就推定为通讯作者，只有原文明示才显示通讯身份。独立列出论文全部署名组织，只有一个组织时不编号；作者引用量优先使用用户选填值，否则通过完整标题定位 Semantic Scholar 论文，核对论文标识、作者署名及单位后读取关联档案统计；限流或未核实时省略，不按同名猜测，不查询 Google Scholar 引用量；只在网络上核实具体论文录用/出版信息后显示期刊/会议，不能把投稿、预印本或作者其他论文的会议当作录用；项目与官方代码链接（如有）。阅读覆盖范围另作简短元信息。
2. 动机：具体问题、已有方法的限制、作者的工作假设。若作者没有交代方法来由，指出缺口；可提出解释但标为助手理解。
3. 方法：输入输出、关键模块、训练目标、训练/推理流程、重要改动及必要公式；说明它如何回应动机，避免只罗列模块。
4. 实验结果：任务、数据、基线、指标、关键结果与消融。引用表中数据时必须列出相关原表（含完整数据及表标题），比较应保留实验条件与局限。缺少证据时直接说明。
5. 结论：回扣动机，回答最初的问题，总结方法与实验最终支持的认识、适用范围和未解决问题。区分作者主张、证据支持和助手判断，不重复摘要、实验数字或新增未经核实的结果；速览约 100–180 字，精读可更细致。
6. 助手判断：所有阅读模式都必须单独给出简短、实质的评价与阅读建议。评价思想价值、证据强弱及边界，结合用户背景建议阅读优先级、值得自己读的部分或一个小验证。论文与当前主线无直接联系时明确说明，从通用研究方法或学术视野给出启发，不牵强绑定研究主线，不重复摘要和实验数字。速览约 150–250 中文字。

左右子图称为 Left / Right，保留原有 (a)/(b) 标记。

### 图表

动机、方法、实验所需的图不可省略；优先提取原文对应图与图注，保持标签、坐标、单位和图例可读。内部核对每个候选的含义与边界，最终只围绕入选证据讲清研究故事。实验数据在表中时也应保留关键表格或准确重排并注明来源。不要仅贴整页论文截图。

原文没有对应图时，可补教学示意图并明确标记“助手绘制”；不能冒充原文证据。原文不可得时，先交付标明局限的文字预览或说明图表缺失，不能声称完整图文速览已完成。

### 公式与代码

速览与中文精读通常只保留必要公式。每条公式用一个短句概括功能与目的，必要时说明关键符号；不使用“思想与符号”“实现连接”等固定标签，不复述公式已经明确给出的实现步骤。教材式数学精读仍可展开数学对象、假设、推导思想与实现联系。没有代码来源时，不编造源码路径；伪代码标为教学示例。

## 中文精读：研究故事的细致展开

沿用速览的动机 → 方法 → 实验 → 结论结构及图文穿插方式，但不使用速览的约 1000 字限制。每章按材料展开约 500–900 字，图表多时可分批继续；重点是解释设计选择为何成立、模块输入输出、训练与推理的差别，以及实验条件、基线、消融和适用边界，不靠复述图注增加篇幅。展开时回到当前论文原文核对，不仅改写简短框架。

原文标题与日期、无标题蓝色完整摘要框、论文相关沿用共同模板。重点在正文标色，不另写重复的段落导读。图表使用原始 Figure/Table 编号，左右子图用 Left/Right；引用表中数字保留对应原表与表标题，不显示 PDF 页码。公式给出含义及实现连接；数学对象的系统铺垫与推导链留给数学精读。

## 教材式数学精读：按需模式

若当前用户配置了参考学习稿，仅学习其解释方式；不得用样例替代当前论文的证据。

学习其解释顺序：

问题动机 → 对象和记号 → 物理/几何图像 → 关键公式为何自然出现 → 为什么目标可训练 → 训练/采样伪代码 → 实验与局限 → 返回原文的导航 → 结论。

先厘清随机变量、实现值、密度函数、算子、向量场与轨迹。说明训练时已知与未知量、采样时可用与不可用量。SDE/ODE 需要说明时钟方向、噪声尺度、离散化以及边缘分布相同不等于路径相同。相同梯度不等于逐批次损失或梯度相同。

保留原文公式编号对照，新增公式另行标注。明确假设、近似和适用范围；物理类比需交代成立范围。关键推导应解释“为什么需要这一步”和如何指导实现，完整证明仅在有助于解决阅读障碍或用户要求时展开。

正文保留用户必需的动机、方法、实验、结论；不得以展开数学为由省略实验。最后以结论收束认识、假设与边界，保留教材式讲解，不重复前面的推导。

### 版式

参考采用单栏中文阅读版、充足留白、深蓝色章节标题、细分隔线、清晰的公式块、简洁页眉页码和原文导航。长篇可用可点击目录。首版可沿用此方向，PDF 的字体尺寸与布局应适配纸张，而不是直接缩放网页。

交付前渲染检查中文字体、数学符号、图表标签、分页和溢出。排版检查不替代内容核查。

## 持续问答

以已核实的论文版本为依据，引用页码/章节/图/公式位置。若问题超出所读内容，应先查相应原文；无法查到时指出范围。可以跨论文比较，但分别核实来源，不把后来的变体或常识当成原论文提出的内容。
