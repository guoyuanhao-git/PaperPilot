# 首页演示素材

这些素材用于根目录 README，不参与应用运行。

- `banner.svg`：本项目制作的矢量封面，沿用现有绿色 P 标识；节点与连线是概念示意。
- `discovery.png`：真实热点发现界面，使用三条合成日报记录展示概括、解读入口和待读操作。
- `reading.png`：真实阅读与交流界面，使用合成论文、示例报告和对话展示表格与数学公式排版。
- `knowledge.png`：真实二维图谱界面，使用演示研究主线和合成节点 / 连线展示分层浏览。

截图在 macOS Chrome 中使用隔离临时数据目录制作，没有读取个人账户资料、调用模型或修改日常论文库。截图内容不代表真实科研结论、真实模型输出效果或具身日报实际收录。请勿将这些演示数据导入产品默认账户。

更新截图时保持这一边界，并在 README 保留演示说明。源码打包仅显式纳入以上四个图片文件，不开放整个文档目录的任意图片打包。

首页结构参考了 [Paperlib](https://github.com/Future-Scholars/paperlib)、[Khoj](https://github.com/khoj-ai/khoj) 与 [Open Notebook](https://github.com/lfnovo/open-notebook) 的定位、功能展示与快速开始组织方式。文案和图片由本项目重新制作，没有复用它们的截图或标识。
