# 语言适配开发说明

PaperPilot 的应用界面统一使用中文，中英文 README 用于介绍项目。应用不提供界面语言切换；个人资料、已有报告和笔记保留原文。

如需基于源码适配其他语言，建议按以下边界实施：

- 将界面文字抽取为显式词条，分别处理静态标签、动态计数、错误提示及无障碍属性。不要扫描全页中文并替换，以免改写题名、账户名、个人思考或模型回复。
- 重新检查按钮宽度、导航、表单和窄屏布局；会议模块使用 Shadow DOM，需独立适配。
- 界面语言与模型生成语言分别设计。报告、问答、摘要翻译、章节标签、长度校验、缓存和 PDF 导出需要一起核对，不能只追加一句输出语言提示。
- 保留公共业务规则和账户隔离。语言切换不得重新生成已有内容、消耗模型额度或丢失未保存的草稿。
- 使用合成资料验证不同语言的显示、持久化和导出，不提交个人数据或凭据。

此前试验性的 ui_language 设置不再由界面或业务流程使用；旧账户即使保留该字段，也不会改变中文显示，无需清理个人数据库。
