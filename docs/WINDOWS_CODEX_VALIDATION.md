# Windows Codex 真实接入验收

这是 Windows 适配的后续任务。此前的离线验收不等于真实模型接入通过。本轮仅验证 Codex 订阅，不测试 DeepSeek，不改产品设计。

用户将本任务交给 Windows 助手执行时，授权进行下述小规模真实 Codex 订阅调用；可能消耗订阅额度，不使用 OpenAI API Key。首次排查最多 20 次 PaperPilot 底层模型调用，包含重试及被取消的调用；达到上限先总结，不能无限重试。这个限制针对验收工具，不改应用业务重试策略。真实模型调用串行进行，三并发与第四任务排队用模拟模型复核。

## 工作区与协作

- 在现有 `guoyuanhao-git/PaperPilot` 项目和 `codex/windows-compat` 分支继续，先检查 Git 状态并保留未提交工作。阅读 AGENTS.md、docs/WINDOWS_HANDOFF.md 和 docs/WINDOWS_VALIDATION.md 的最终结果。
- PR #1 尚未合并时继续更新该 PR；如果它已合并，从最新 main 建新的 Windows 修复分支和草稿 PR。不要覆盖远端新提交、强推或合并 main。
- macOS 端同时维护公式修复、高清裁图与 512 MiB 缓存，以及 Windows 启停文件打包修复。这些可能尚未推送，不要因远端暂时没有就回退、重复实现或等待它们。冲突时保留双方功能。
- 使用独立测试数据目录、合成账户、合成 PDF、空闲本机端口，暂停测试账户的自动任务。不要读取其他账户资料、真实论文或机主私人文件。实际双击入口的子进程也须继承同一测试数据目录。

## 先验证接入，不把检查状态当成推理成功

1. 记录 Windows、Python、Node 和 Codex CLI 版本，检查安装路径和实际可执行文件类型（含 npm `.cmd` 包装器）。通过当前 CLI 的 `--help` 核对调用参数，不猜测参数是否支持。
2. 从 PaperPilot 模型设置获取当前项目目录、测试账户 ID、端口和协助接入命令。验证用户复制该命令后可在普通 PowerShell 运行，不能依赖开发助手恰好激活的虚拟环境；如果使用了错误的全局 `python`、Unix 脚本或不正确的路径转义，修复公共接入命令生成逻辑。中文、空格路径至少覆盖一次。
3. 先执行本地 `--check`。沿用该测试账户可用的官方 Codex 登录；如需要登录，通过 PaperPilot 的官方 CLI 登录流程由用户完成浏览器授权。桌面助手可用并不能证明测试账户对应的 CLI 登录已配置。不要复制/打印 auth.json、密钥或令牌，不登出机主全局账户，不提取其他软件的凭据，不更换为 API Key。
4. 再执行本地检查和一次真实短连接测试。区分“CLI 存在”“已通过订阅登录”“真实推理成功”。默认使用 PaperPilot 已配置模型；若账号无权限，报告准确原因，由用户选择可用模型，不能偷偷改全项目默认模型。

## 从 PaperPilot 实际路径验收

- 通过真实应用的 providers 适配器和后台任务发起调用，不能只手动运行一条 `codex exec` 就宣称应用已通过。保留公共输出校验、隔离目录及工具限制，不用放宽沙箱或开放 shell 工具来掩盖兼容错误。
- 合成一份两页、含中英文、简单公式和一张可区分内容的图表的 PDF。验证一次小型速览生成，实际走结构化输出和图像输入，报告正确落盘且可重新打开。用一个依赖图中内容的简短问题检查图片确实被使用，不以 JSON 字段存在冒充成功。
- 同一篇论文连续发送两条短问题，第二条依赖第一条上下文；确认第二条能回复，中文、数学符号、落盘和重开正常。
- 启动一次真实生成或问答，在运行中点击停止。确认页面解除等待、任务取消、旧报告/旧回答保留、晚到结果不会覆盖；通过本次任务进程树检查包装器及实际模型进程是否结束。只处理本测试创建的进程，不能按名称杀掉所有 node/codex/python。取消后用下一条短问答验证可继续使用。如请求过快结束，最多再试一次，仍未捕获则记录真实取消未测，保留模拟进程树测试。
- 核查 Windows `.cmd` 调用的参数转义、UTF-8 输入输出、超时和子进程回收。如发现兼容问题，以最小跨平台修复处理，保留 macOS 行为；不要把模型输出误判、账号权限、额度耗尽和网络失败混为代码问题。
- 三任务并发/第四排队、超时、异常与晚到响应保护仍用模拟模型验证；不额外真实生成完整知识图谱或 PPT。

停止本次测试服务，清理合成数据和临时进程；如需保留隔离测试账户的登录以便复测，告知用户保存位置，不读取其内容，不清除机主其他登录。只在浏览器授权、系统权限、模型选择或达到预算时请求用户介入，其他排查自主完成。

将修复和脱敏验证报告提交、推送到适配分支并更新草稿 PR，不合并 main。若无需代码修复，也提交验收记录。最后报告 PR 链接，以及接入、真实报告、连续对话、取消与重试分别是否通过。
